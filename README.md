# 利昂图书馆预约系统签到码生成器

一个纯前端的单页 HTML 小工具，用于演示“签到码生成”的页面效果。  
项目只有一个 `HTML` 文件，没有后端、没有数据库、没有额外依赖，下载到本地后可直接用浏览器打开，也可以 fork 到自己的仓库后通过 GitHub Pages / GitHub Actions 进行静态部署。

> 说明：本项目仅供学习、演示和页面展示使用，不代表任何真实系统功能，也不与“利昂图书馆预约系统”存在官方关联。

---

## 项目特点

- **单文件部署**：核心内容只需要一个 `.html` 文件
- **开箱即用**：下载后直接双击即可在浏览器中打开
- **纯静态页面**：无需安装 Node.js、Python、PHP 等环境
- **可 fork 部署**：可上传到 GitHub 仓库，配合 GitHub Pages / Actions 发布
- **可二次修改**：可自行调整样式、文案、生成规则和页面布局

---

## 使用方式

### 方式一：本地直接打开

1. 下载本项目源码
2. 找到 `index.html`
3. 双击打开，或右键选择浏览器打开
4. 页面即可正常使用

适合：
- 只想本地查看效果
- 临时演示
- 不想折腾部署环境

---

### 方式二：fork 后部署到 GitHub

1. 将本项目 fork 到你自己的 GitHub 仓库
2. 保持 `index.html` 在仓库根目录，或者按你自己的目录结构调整
3. 打开仓库设置中的 **Pages**
4. 选择静态站点发布来源，例如：
   - `main` 分支
   - `/root` 目录
   - 或者你配置好的 `gh-pages` 分支
5. 保存后等待 GitHub 自动生成访问地址

适合：
- 想长期在线访问
- 想发给别人看
- 想把页面作为静态站点托管

---

### 方式三：使用 GitHub Actions 自动部署

如果你希望每次推送代码后自动发布，可以使用 GitHub Actions 进行静态部署。

基本思路：

1. fork 本仓库
2. 在仓库中启用 GitHub Actions
3. 添加静态部署工作流
4. 每次提交后自动构建并发布页面

常见场景：
- 你经常修改页面内容
- 你希望自动更新线上版本
- 你想把仓库直接当成静态站点项目维护
